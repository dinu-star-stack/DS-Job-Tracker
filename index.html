About DS Job Tracker

DS Job Tracker is a smart job application management system designed to help job seekers organize and manage their job applications in one place.

📌 Main Features

  • Job application tracking
  • Application status management
  • Interview date, time and type tracking
  • Notes and next-action management
  • Application timeline
  • Job preparation guidance
  • Application checklist
  • CV Match
  • Application statistics dashboard

📄 CV Match

The CV Match feature allows users to upload their CV in PDF or TXT format and compare it with the selected job role.

Currently supported roles:

Software QA Software Engineer Business Analyst Frontend Developer Data Analyst

🛠️ Technologies

HTML • CSS • JavaScript • LocalStorage • PDF.js

🎯 Purpose

The goal of this project is to make job application tracking more organized while helping users prepare for different IT career opportunities.
